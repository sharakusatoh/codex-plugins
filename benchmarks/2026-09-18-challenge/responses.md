~~~~text
```python
def apply_events(events):
    latest = {}

    for event in events:
        event_id = event["id"]
        revision = event["revision"]
        previous = latest.get(event_id)

        if previous is None or revision > previous[0]:
            latest[event_id] = (
                revision,
                event["account"],
                event["amount"],
            )

    totals = {}
    for _, account, amount in latest.values():
        if amount != 0:
            totals[account] = totals.get(account, 0) + amount

    return {account: total for account, total in totals.items() if total != 0}
```

入力を1回だけ走査し、id別に最大revisionを保持。同版は上書きせず、取消しも記録して古い版の復活を防ぐ。最後に集計するためaccount変更にも対応でき、入力も変更しない。
~~~~

## sherlock-report / plugin

### Turn 1

~~~~text

追加する一種類は、局所的な刺激履歴を統制した系列規則違反実験です。複数部位への刺激系列で規則を形成し、同じ検査刺激が規則に従う条件と違反する条件を比較します。検査部位、強度、出現頻度、直前の刺激履歴と間隔を揃え、系列の割り当てを入れ替えます。主要評価項目は両条件の誘発応答差とし、解析方法を事前に固定します。

局所的な順応だけが原因なら、履歴を揃えた条件間の差は予測しにくくなります。規則違反に選択的な応答が再現すれば、単なる未順応経路の動員を越えた、文脈に依存する処理を支持します。ただし、無意識的な系列学習も候補に残り、主観的経験の実証にはなりません。差がなければ、その処理を支持する根拠は増えませんが、意識の不在も確定しません。

会議では、成果を「刺激履歴に依存する可逆的な応答変化」と記述し、予算は競合する機序の識別に使うことを提案します。意識仮説は保留し、経験を示す表現は結論から外します。
~~~~
